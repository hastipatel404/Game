# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer and see who wins!

## 🚀 Features

- ✊ Rock, 📄 Paper, and ✂️ Scissors choices
- 🤖 Computer makes a random choice
- 🏆 Automatically determines the winner
- 📊 Keeps track of player and computer scores
- 🔄 Reset game functionality
- 📱 Responsive and user-friendly design
- ⚡ Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
